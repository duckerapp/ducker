# Что дальше

- **Клиент для компьютера** — Windows, Linux и macOS.
- **Стеклянный стиль:** полупрозрачные панели как второй вариант оформления.
- **«Только через VPN»:** у выбранных приложений нет интернета вовсе, пока VPN выключен.
