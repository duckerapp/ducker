# Шаблоны конфигурации

По умолчанию **«Из подписки»** применяет исправный конфиг провайдера без изменений.
Для подписки по ссылке пользователь может выбрать **«ducker · Россия»** в **«Подписки → ⋯ →
Конфигурация»**. Тогда серверы и `proxy-providers` берутся из подписки, а группы, правила,
DNS и исключения приложений — из шаблона. Зависимости узлов и настройки проверки поставщиков
серверов сохраняются; шаблон добавляет свои проверки. `ducker-override-user` провайдера не
блокирует строки приложений шаблона. Зашифрованные подписки в этом режиме не поддерживаются.

Смена заменяет ручные правки. Новый режим начинает действовать после успешного применения.
При ошибке остаётся прежний рабочий конфиг. «Из подписки» возвращает маршрутизацию провайдера.
[Инструкция пользователю](../users/faq.md#шаблоны-конфигурации).

Если в подписке обычный список ссылок на серверы, ducker автоматически подставляет их во встроенный шаблон.
Для новой подписки он также может извлечь серверы из сломанного конфига и показать карточку
ошибки. При неудачном обновлении уже рабочей подписки сохраняется её прежний конфиг.

## Что в шаблоне

- **Маршрутизация под Россию.** Заблокированное идёт через узел, российские сайты и сервисы —
  напрямую, локальная сеть — мимо VPN.
- **Группы.** «Основной профиль» со списком всех узлов и автоматическим выбором «⚡ AUTO»,
  «Без VPN» для прямых соединений.
- **Наборы правил** подгружаются по ссылкам из шаблона и обновляются сами.
- **Локального порта прокси нет:** другие приложения на телефоне не находят прокси на
  `127.0.0.1`.
- **Свой DNS** и синхронизация времени.
- **Адрес подписки идёт мимо туннеля,** чтобы её можно было обновить и тогда, когда узлы не
  отвечают.

Сам файл — в репозитории:
[`app/src/main/assets/ducker/template.yaml`](https://github.com/duckerapp/ducker/blob/main/app/src/main/assets/ducker/template.yaml).
В нём подробные комментарии к каждому решению.

## Если нужна своя маршрутизация

Отдавайте готовый конфиг mihomo — так, как описано на странице
[«Подписка для ducker»](start.md). В режиме «Из подписки» используется этот конфиг. Пользователь всё равно может явно выбрать шаблон.
