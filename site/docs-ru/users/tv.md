# Установка на телевизор

Телевизору нужен файл ducker — APK. Проще всего передать его с телефона по домашней сети программой
[LocalSend](https://localsend.org): она бесплатная, с открытым кодом и без рекламы. Ставить её нужно только на
телевизор — телефон отправит файл обычным браузером.

Понадобятся телевизор или приставка на Android TV или Google TV и телефон, оба в одной домашней сети Wi-Fi.

## 1. Скачайте ducker на телефон

Откройте на телефоне [выпуски](https://github.com/duckerapp/ducker/releases) и скачайте файл
`ducker-…-armeabi-v7a.apk` — он ставится почти на любой телевизор. Для современного телевизора или приставки
нужен `ducker-…-arm64-v8a.apk`. Если файл не установится на шаге 5, повторите с другим.
На сам телефон устанавливать файл не нужно.

## 2. Поставьте LocalSend на телевизор

На телевизоре откройте Google Play, найдите LocalSend и установите.

## 3. Включите приём по ссылке

Откройте LocalSend на телевизоре и выберите «Получить по ссылке»: сразу после запуска это две стрелки вниз и ОК.
Поставьте галочку «Автоматически принимать запросы» — тогда телевизор ничего не переспросит. Затем нажмите значок
QR-кода рядом с адресом.

Рамка выбора в LocalSend бледная: смотрите внимательно, какой пункт чуть светлее остальных.

![LocalSend на телевизоре: «Получить по ссылке» с галочкой «Автоматически принимать запросы»](../assets/shots/tv-guide-link.png){ loading=lazy }

![QR-код ссылки на экране телевизора](../assets/shots/tv-guide-qr.png){ loading=lazy }

## 4. Отправьте файл с телефона

Наведите камеру телефона на QR-код и откройте ссылку. В браузере нажмите **Upload** и выберите скачанный файл
ducker. Когда на телевизоре появится «Завершено», файл на месте.

Если QR-код не сканируется, наберите адрес под ним в браузере телефона, например `http://192.168.1.23:53317` —
у вас он будет свой.

![Телевизор принял файл ducker: «Получение файлов», «Завершено»](../assets/shots/tv-guide-received.png){ loading=lazy }

## 5. Установите ducker

На телевизоре нажмите два раза вверх, чтобы выбрать строку с файлом, и ОК. Android попросит разрешить установку из
LocalSend: включите переключатель и нажмите «Назад».

![Android TV: «Установка неизвестных приложений», переключатель для LocalSend](../assets/shots/tv-guide-unknown.png){ loading=lazy }

Появится «Установить приложение?». Фокус стоит на «Отмена» — нажмите влево, на «Установить», и ОК. Затем «Открыть».

![«Установить приложение?» с выбранной кнопкой «Установить»](../assets/shots/tv-guide-install.png){ loading=lazy }

## 6. Добавьте подписку

В ducker на телевизоре нажмите «Добавить подписку». Есть три способа:

- **Камерой телефона,** любого, ducker не нужен: наведите камеру на код на телевизоре, откройте предложенную ею
  страницу и вставьте туда ссылку. Только в своей домашней сети: тот, кто управляет сетью, может подменить страницу
  и прочитать ссылку.
- **Сканером ducker на телефоне,** если ducker уже стоит на телефоне, — безопасно в любой сети: там «Подписки» →
  «Добавить» → «Сканировать QR», и наведите камеру на код на телевизоре. Подписка уйдёт на телевизор по домашней
  сети, зашифрованной.
- **Ссылкой вручную:** выберите поле, наберите ссылку от провайдера экранной клавиатурой и нажмите «Добавить».

![ducker на телевизоре: «Добавить подписку» с QR-кодом и полем для ссылки](../assets/shots/tv-guide-add.png){ loading=lazy }

![Ссылка набирается экранной клавиатурой пультом](../assets/shots/tv-guide-typed.png){ loading=lazy }

Готово: на главной нажмите кнопку включения.

![Главная ducker на телевизоре после добавления подписки](../assets/shots/tv-guide-home.png){ loading=lazy }

После этого LocalSend больше не нужен: новые версии ducker приходят в само приложение. Снимите галочку
«Автоматически принимать запросы» или удалите LocalSend.

## Если под рукой нет телефона

Скопируйте APK на флешку с компьютера, вставьте её в телевизор и откройте файл файловым менеджером — на многих
телевизорах он встроен. Дальше — как в шаге 5: разрешите установку этому файловому менеджеру и нажмите «Установить».

Если телевизор просит разрешить приложения непроверенных разработчиков, см.
[что нажать](faq.md#android-просит-разрешить-приложения-непроверенных-разработчиков).
