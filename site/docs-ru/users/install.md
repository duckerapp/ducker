# Установка

Скачайте APK из [выпусков](https://github.com/duckerapp/ducker/releases) и откройте его на
телефоне или телевизоре. Android попросит разрешить установку из этого источника — для приложений
не из Google Play это нормально. Google Play Защита может ещё предложить сначала проверить
приложение: [что нажать](faq.md#google-play-защита-предлагает-проверить-приложение).

Какой файл брать:

- `arm64-v8a` — почти любой телефон новее 2017 года;
- `armeabi-v7a` — старые телефоны и многие телевизоры; берите, если первый не ставится.

Нужен Android 10 или новее. Руками ducker ставится один раз, дальше он
[обновляется сам](#обновления).

## Первая подписка

«Подписки» → «Добавить» → вставьте ссылку от провайдера, отсканируйте его QR-код или выберите
файл. Ссылка вида `ducker://install-config?url=…` открывает то же окно прямо из письма или чата.
Затем нажмите кнопку включения на «Главной» и разрешите запрос Android на VPN.

Подробно, со всеми способами, — в разделе
[Как добавить подписку](faq.md#как-добавить-подписку).

## На телевизоре

Тот же APK работает на Android TV и Google TV. Набирать ссылку пультом не нужно: нажмите на
телевизоре «+» — появится QR-код. Отсканируйте его в ducker на телефоне («Подписки» →
«Добавить» → «Сканировать QR») и подтвердите отправку: подписка уйдёт на телевизор по домашней
сети, зашифрованной. Телефон и телевизор должны быть в одной домашней сети.

Как вообще передать APK на телевизор, по шагам: [Установка на телевизор](tv.md).

## Обновления

- **ducker сам проверяет** обновления дважды в день и при открытии. Новая версия появляется на
  главной и в уведомлении вместе со списком изменений; одно касание — и она скачается и встанет,
  а VPN включится обратно сам.
- **«Обновлять автоматически»** (в настройках): новые версии скачиваются по Wi-Fi и ставятся, пока
  экран погашен, обычно ночью. Выключено, пока вы не согласитесь. Android 12 и новее; на Android
  10–11 система каждый раз спрашивает подтверждение.
- **«Бета-версии»** (в настройках): новые версии на несколько дней раньше остальных. Удачная бета
  потом уходит всем тем же самым файлом.
- **Откуда.** Список версий берётся с GitHub, а если он не отвечает — с
  [зеркала на GitLab](https://gitlab.com/duckerx/ducker) или jsDelivr. Перед установкой ducker
  сверяет контрольную сумму файла и то, что он подписан тем же ключом, что и установленное
  приложение: чужой файл не встанет.

## Проверка файла

- К каждому выпуску приложен `SHA256SUMS` — контрольные суммы его APK.
- В описании каждого выпуска есть ссылка на отчёт [VirusTotal](https://www.virustotal.com) для
  каждого APK: этот самый файл проверили десятки антивирусов. Свою копию можно загрузить туда
  самому и сравнить.
- Всё, что есть в APK, собирается из
  [репозитория](https://github.com/duckerapp/ducker/blob/main/docs/README.ru.md#сборка); сборку
  можно повторить самому.

## Проверка разработчиков Google

С 2027 года сертифицированные телефоны и телевизоры на Android ставят приложения не из Google Play,
только если их разработчик зарегистрирован в Google; в Бразилии, Индонезии, Сингапуре и Таиланде
это началось ещё в 2026-м. ducker не зарегистрирован. На таких устройствах Android один раз
попросит разрешить приложения непроверенных разработчиков: для этого нужны PIN-код, перезагрузка
и сутки ожидания. После этого ducker ставится и обновляется как раньше; если снова выключить эту
настройку, обновления ducker перестанут ставиться. Установки через `adb` это не касается.
[Что нажать](faq.md#android-просит-разрешить-приложения-непроверенных-разработчиков).

## Управление из других приложений

Приложение понимает интенты — удобно для Tasker и ярлыков.

Для внешних START/STOP/TOGGLE включите «Настройки» → «Приватность» → «Управление из других
приложений». По умолчанию доступ выключен, в том числе после обновления уже установленного
приложения. Разрешение действует для всех приложений, способных отправить эти команды. Виджеты,
плитка и ярлыки самого ducker работают без него; добавление подписки по ссылке требует
подтверждения.

| Действие | Интент |
|---|---|
| включить | `am start -a app.ducker.android.action.START_CLASH` |
| выключить | `am start -a app.ducker.android.action.STOP_CLASH` |
| переключить | `am start -a app.ducker.android.action.TOGGLE_CLASH` |
| добавить подписку | `ducker://install-config?url=<ссылка>` |
